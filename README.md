# 🎵 Entretons

Entretons é um blog informativo desenvolvido com o objetivo de divulgar a música microtonal, apresentando conceitos, artistas, movimentos e álbuns relacionados a essa vertente musical.

Além do conteúdo educativo, a plataforma conta com sistema de autenticação, quiz interativo e dashboard para acompanhamento do desempenho dos usuários.

## 🎯 Objetivo

O projeto foi desenvolvido como Projeto Individual do curso de Ciência da Computação da São Paulo Tech School.

Seu principal objetivo é praticar todos os conceitos ensinados ao longo do primeiro semestre do curso a partir de um tema pessoal.

## 🏁 Funcionalidades

* Sistema de cadastro e login
* Feature de like e dislike
* Quiz sobre música microtonal
* Dashboard com KPI'S e gráficos
* Persistência de dados utilizando banco de dados MySQL

## ⚙️ Configuração do Banco de Dados

1. Abra o MySQL.
2. Execute o script SQL disponibilizado no projeto.
3. Crie o banco de dados e suas respectivas tabelas.
4. Verifique se as credenciais configuradas no arquivo `.env` correspondem às do seu ambiente local.

---

## 🔐 Configuração do Ambiente

Crie um arquivo `.env` na raiz do projeto contendo as configurações do banco de dados.

Exemplo:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=sua_senha
DB_DATABASE=entretons
DB_PORT=3306
```

Ajuste os valores de acordo com a configuração do seu ambiente.

---

## 🚀 Instalação

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Acesse a pasta do projeto:

```bash
cd entretons
```

Instale as dependências:

```bash
npm install
```

---

## ▶️ Executando a aplicação

Inicie o servidor:

```bash
npm start
```

Após iniciar a aplicação, acesse:

```text
http://localhost:3333
```

ou a porta configurada no projeto.
